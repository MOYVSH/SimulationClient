本模块为纯文档型叶子目录，不包含任何可执行代码，由两份 Markdown 文件构成：
- `.simulationdoc/unity_simulation_design_v1.md`：顶层技术设计，给出 Terrain → WorldData → WorldGrid → ChunkManager → A* → View 的分层边界、Cell/Chunk/TreeData/BuildingData/RoadData/WorkerData/JobData 等核心数据结构及性能目标（TreeView ≤ 500、CPU < 10ms）。
- `.simulationdoc/.qoder/specs/spec-20260706172954.md`：将设计文档拆解为 Phase 0~6 的可执行任务表，每个任务明确关键产出文件名（如 `WorldGrid.cs`、`AStarPathfinder.cs`、`SimulationTickManager.cs`）、依赖关系与验收标准，并给出最小可玩里程碑路径。
依赖方向单向：开发计划引用设计文档中的架构约束，不反向影响；两者共同作为后续 C# 源码实现的唯一权威来源。
