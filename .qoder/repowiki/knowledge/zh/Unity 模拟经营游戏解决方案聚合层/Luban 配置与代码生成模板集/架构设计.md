本模块是 Luban 数据配置系统的「工程模板」层，围绕 `Template/luban.conf` 这一根配置组织：
- 顶层 `luban.conf` 通过 `groups`（c/s/e）划分客户端/服务端/枚举分组，`schemaFiles` 声明 `Defines`、`__tables__.xlsx`、`__beans__.xlsx`、`__enums__.xlsx` 四份元数据源，`targets` 将分组映射到 server/client/all 三个目标，统一由 `Tables` 管理器 + `cfg` 顶层模块输出。
- `Defines/builtin.xml` 以 XML module 形式注册 vector2/3/4 等内建 bean，作为所有表的共享类型基线。
- `Datas/` 存放示例 Excel 数据表，遵循 `__xxx__.xlsx` 前缀约定（tables/beans/enums），供首次运行验证。
- `Template/Luban/Templates/` 按「语言-序列化后端」命名（如 `cpp-sharedptr-bin`、`cs-dotnet-json`、`go-json`、`rust-bin`、`flatbuffers`、`pb`、`gdscript-json` 等），每个子目录包含一组 Scriban 模板（`.sbn`），分别产出 bean/table/tables/schema/lib/mod/toml 等文件；`common/` 下各语言的 `enum.sbn` 被多目标复用，体现模板继承关系。
- `Template/Luban/` 同时打包了 Luban 运行时（`Luban.exe`、`Luban.dll` 及 `Luban.*.dll` 插件程序集、`deps.json`、`runtimeconfig.json`、`NLog.dll`、`Scriban.dll`、`Neo.Lua.dll` 等），使该目录可脱离外部安装独立执行。
- `gen.sh` / `gen.bat` 是入口脚本，固定调用 `dotnet $WORKSPACE/Tools/Luban/Luban.dll -t all -d json --conf luban.conf -x outputDataDir=output`，将当前目录作为 CONF_ROOT 驱动生成。
依赖方向单向向外：模板与 conf 仅消费 Luban 运行时，不被业务代码反向引用。
